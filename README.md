Developed a Real-Time CAN Bus Anomaly Detection System using Python and Machine Learning to identify cyberattacks in automotive networks. The system analyzes CAN traffic, extracts statistical and entropy-based features, and uses Random Forest and Isolation Forest models to detect anomalies such as DoS, spoofing, and replay attacks. A real-time dashboard was implemented for live monitoring and alert generation. The solution achieved approximately 94% detection accuracy with low-latency performance, enhancing vehicle network security through intelligent threat detection and analysis.
